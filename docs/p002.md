# Gate P002

Baseline: 991de98632bd. Versão-alvo: v0.1.0-preview.2.

## Cenários

| Cenário | Resultado | Evidência |
| --- | --- | --- |
| Concorrência | PASS | Limite global entre dois jobs e deduplicação de pedidos simultâneos. |
| Recuperação | PASS | Encerramento abrupto do subprocesso de serviço durante uma tentativa. Ao reiniciar, a tentativa e a fila foram recuperadas como BLOCKED sem reexecução. |
| Falha e cancelamento | PASS | Falha propagada por toda a cadeia de dependências, com conclusão da tarefa independente. Timeout e cancelamento encerraram árvores de subprocessos. Cancelamento na fila impediu execução. |
| Autenticação | PASS | Tokens de transporte e administração não dão acesso a jobs. Transferência de liderança revoga a chave anterior. |
| Git e encerramento | PASS | Conflito em cherry-pick bloqueou a integração das dependências. Commits permaneceram nas branches das tarefas. HEAD, índice e conteúdo original permaneceram intactos. O encerramento não integra commits. |
| Effort e override | PASS | Testes automatizados validaram incompatibilidade e isolamento do override. O aceite real capturou os argumentos nativos de três CLIs. |
| Aceite real com revisão e correção | PASS | OpenCode analisou, Claude Code implementou, Codex apontou a falta de um marcador e revisou o segundo commit que o acrescentou. |
| Antigravity IDE | PASS como cliente | A IDE 1.107.0 descobriu o servidor no arquivo de workspace gerado pelo instalador. A chamada visível de hivemind_status retornou service=hivemind, concurrency=2, running=0. |
| Instalação e upgrade global Windows 11 | PASS | npm install --global em prefixo isolado. Upgrade da Preview 1 pública para o pacote candidato, com shim, skill, configuração, token local e job planejado preservados. |

## Harnesses

| Harness | Resultado | Parâmetro observado |
| --- | --- | --- |
| Codex CLI 0.166.0 | PASS em revisão e escrita na worktree com MXC | --sandbox read-only na revisão, --sandbox workspace-write na escrita, --enable prefer_mxc e -c model_reasoning_effort="low". |
| Claude Code 2.1.292 | PASS na implementação e na correção | --model claude-sonnet-4-6 --effort medium na implementação, --effort high na correção. |
| OpenCode 2.2.6 | PASS na análise da fixture | --model opencode-go/beam-free#low. |
| Google Antigravity IDE 1.107.0 | PASS como cliente MCP. NOT TESTED como executor. | A consulta foi feita na IDE pela ponte STDIO. |

Antes da correção, o Codex recebeu workspace-write e a ferramenta de edição informou bloqueio por sandbox. O probe nativo independente também falhou no modo padrão com “registered Core launch requires an installed app”. O probe com MXC gravou o marcador na fixture. O adapter passou a preferir MXC no Windows na configuração padrão, e a mesma tarefa de escrita produziu um commit. O Codex continua responsável por aplicar requisitos de sandbox e aprovação. [Documentação oficial do sandbox Windows](https://learn.chatgpt.com/docs/windows/windows-sandbox)

## Reproduzir

Suíte automatizada, com adapters determinísticos e Git e subprocessos locais:

~~~powershell
npm ci
npm run typecheck
npm run lint
npm test
~~~

Aceite real separado. Selecione modelos disponíveis na sua conta e mantenha os limites autorizados.

~~~powershell
$env:HIVEMIND_TEST_OPENCODE_MODEL = 'opencode-go/beam-free'
$env:HIVEMIND_TEST_OPENCODE_EFFORT = 'low'
$env:HIVEMIND_TEST_CLAUDE_MODEL = 'claude-sonnet-4-6'
$env:HIVEMIND_TEST_CLAUDE_EFFORT = 'medium'
$env:HIVEMIND_TEST_CODEX_MODEL = 'gpt-6.1-sol'
$env:HIVEMIND_TEST_CODEX_EFFORT = 'low'
npm run test:real -- p002
npm run test:real -- codex-write
~~~

O primeiro teste verifica os dois commits, os pareceres de revisão e os argumentos efetivamente encaminhados. O segundo requer escrita pelo sandbox na fixture e confirma o marcador no diff. Use HIVEMIND_KEEP_FIXTURE=1 para conservar os dados localmente.

Para Antigravity, inicie o serviço local, rode hivemind install antigravity . em uma fixture e aplique a configuração de workspace mostrada pelo comando. Abra a fixture na IDE e peça que chame apenas hivemind_status via MCP. Confira a chamada e o resultado no painel do agente. [Configuração MCP no Antigravity](https://antigravity.google/docs/mcp)

Para verificar o pacote global:

~~~powershell
npm run build
npm pack
npm run test:upgrade -- .\hivemind-orchestrator-0.1.0-preview.2.tgz
~~~
