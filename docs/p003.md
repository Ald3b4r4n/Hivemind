# P003 — Operação universal

Baseline 4613a8d33ed06c9a2691c3366e88a0b6fc3f89dd. Versão v0.1.0-preview.3.

## Operação

Requer Node.js 24 e Git 2.45 ou superior.

~~~powershell
npm install -g https://github.com/Ald3b4r4n/Hivemind/releases/download/v0.1.0-preview.3/hivemind-orchestrator-0.1.0-preview.3.tgz
hivemind init
hivemind start
hivemind status
hivemind install codex .
hivemind install codex . --apply
hivemind doctor .
~~~

Edite agents.yaml com seus perfis antes de criar jobs. Defina HIVEMIND_HOME ou passe --home logo após o comando para usar outro diretório de dados. O residente permanece ativo depois que a CLI termina. Use hivemind stop ou hivemind restart para operar o processo. O encerramento autentica a instância via loopback e recusa trabalhos ativos ou enfileirados. Aguarde a conclusão ou cancele tarefas explicitamente pelo MCP. O arquivo service.log contém o último evento do ciclo de vida. O SQLite mantém o histórico de jobs.

O controle do serviço usa um desafio assinado e identifica banco, instância, PID e horário de criação. Uma porta ocupada por uma identidade desconhecida exige diagnóstico. O comando stop solicita encerramento ao processo autenticado. A proteção de instância única depende do lock exclusivo do SQLite. Na recuperação após queda, tentativas ou tarefas enfileiradas incertas ficam bloqueadas para avaliação.

## Upgrade e rollback

1. Na Preview 2, aguarde o término dos jobs e encerre a sessão em primeiro plano de serve. A partir da Preview 3, use hivemind stop.
2. Reinstale o pacote da versão desejada usando o mesmo prefixo npm e mantenha o mesmo HIVEMIND_HOME.
3. Na Preview 3, rode hivemind start e hivemind doctor . Na Preview 2, use hivemind serve.
4. Para atualizar uma skill oficial antiga, revise a prévia de hivemind install <cliente> . --update-skill e depois acrescente --apply. Uma skill personalizada exige integração manual com o conteúdo canônico. O instalador informa o backup das cópias que atualiza.
5. Para restaurar configuração, compare o backup com o arquivo atual e restaure somente a entrada desejada se houver edições posteriores.

~~~powershell
# Upgrade ou reinstalação da Preview 3
npm install -g https://github.com/Ald3b4r4n/Hivemind/releases/download/v0.1.0-preview.3/hivemind-orchestrator-0.1.0-preview.3.tgz

# Rollback dos binários para a Preview 2, depois de parar a Preview 3
npm install -g https://github.com/Ald3b4r4n/Hivemind/releases/download/v0.1.0-preview.2/hivemind-orchestrator-0.1.0-preview.2.tgz
hivemind serve
~~~

A atualização é um procedimento do operador. O pacote não instala autostart ou serviço de sistema. O upgrade e o rollback mantêm o mesmo formato de estado, e o teste cobre configuração, tokens, job, política de aprovação, skill local e uma worktree com arquivo local.

## Limites

As configurações gerenciadas por organizações e a confiança do workspace continuam sob controle de cada cliente. A prévia sinaliza arquivos inválidos, múltiplos formatos e conflitos conhecidos, e fornece uma entrada manual. O instalador OpenCode usa o esquema V2. A autenticação do doctor identifica estados observáveis em Codex e Claude Code. Para OpenCode e Antigravity, a autenticação de modelos é reportada como not-tested.
