# Contribuir

Use Node.js 24 e Git 2.45+. Rode `npm ci`, `npm run build`, `npm run typecheck`, `npm run lint` e `npm test`. Os testes padrão usam adapters falsos e repositórios temporários. Para um adapter novo, documente a interface oficial, as políticas de execução, a descoberta de capacidades e o resultado de um teste real separado.

Prefira commits por alteração funcional. Preserve a skill canônica e a separação entre harness, provedor/modelo e papel. Remova tokens, configurações pessoais e logs privados de relatórios, commits e pull requests.
